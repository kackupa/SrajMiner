# Cold Signal music sketches

Three original techno demos. The game now bundles these same files for its depth-based soundtrack; the MP3s here remain playable on their own.

- **Signal Run** (`signal-run.mp3`): 128 BPM, bright sequenced hook, four-on-the-floor kick, and an airy middle break.
- **Deep Pressure** (`deep-pressure.mp3`): 136 BPM, darker bass and a more mechanical, spacious lead.
- **Descent Transition** (`descent-transition.mp3`): a 59-second journey that opens with the Signal Run sound, gradually shifts from 128 to 136 BPM, changes the bass and harmony, drops to a short breakdown, then arrives at the Deep Pressure sound.

All tracks use only synthesized instruments and deterministic noise; no third-party samples or melodies. To regenerate the WAV masters, run `node music-prototypes/generate.mjs`. The committed MP3 previews are encoded at 192 kb/s from those masters.
