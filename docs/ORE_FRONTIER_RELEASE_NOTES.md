# Ore Frontier: Beyond the First Colony

Local development build, 18 October 2026. Not deployed or published.

- Cryo Shelf and Mars Frontier now form a repeatable two-world expedition. Depart from the docked mothership through the Star map for one core fuel. Unrecovered destinations require one additional unit held for the return.
- First core recovery still grants four fuel. Mine an exposed recovered core for ten seconds to replenish one unit, up to four. Unfinished extraction resets when interrupted.
- Miner cargo, the 50-unit travelling ship hold and stationary planetary stock are separate. Freight uses explicit local source, destination and amount buttons. Construction, basic upgrades and local orders spend Miner, then Ship, then Planet materials. Sales remain miner-only.
- Active extractors fill the local warehouse before the landed ship. Away colonies use only their own warehouse. Finite seams, depletion and the 12-hour catch-up cap remain in effect. Away summaries show actual session-observed stock changes and disclose unavailable history after reload.
- Import nickel for reinforced hull, or use cryocrystal for efficient cooling. Both one-time installations persist. Hull keeps its current percentage; cooling reduces only drilling battery expenditure.
- Schema 32 retains the existing save key and old planetary stock, including reclaimable overflow. Old worlds remain saved and playable, with a confirmed free relocation to Cryo. Legacy stranded states can use a confirmed tow without new fuel or money.
- Other worlds, inhabited-world landings and multiplayer remain previews. No new combat, wallet, token, account or backend systems were added.

Verification evidence and limitations are recorded in `QA.md` and `NEXT_UPDATE_PLAN.md`. Physical Android testing is still user-provided. Local verification does not establish production deployment.
